# Fill in the Frames, Seamlessly — Dashboard (Frontend Prototype)

React + Vite dashboard for the "Fill in the Frames Seamlessly" problem statement: AI/ML optical-flow
frame interpolation to raise the temporal resolution of geostationary satellite TIR imagery
(INSAT-3DS/3DR, GOES-19, Himawari-8).

## Status

Standalone frontend, no backend wired up yet. All animations and metrics are generated by a synthetic
cloud-motion simulator (`src/lib/simulate.js`) with real MSE/PSNR/SSIM/FSIM math computed against it
(`src/lib/metrics.js`) — so the numbers on screen are genuinely calculated, just not from real satellite
data. See the "Pipeline & About" tab in the app for the intended production API contract.

## Run it

```
npm install
npm run dev
```

## Structure

- `src/lib/simulate.js` — synthetic TIR field generator, traditional (linear-blend) and AI-style
  (motion-warp) interpolation.
- `src/lib/metrics.js` — MSE, PSNR, SSIM, FSIM (approx.) computed on the generated fields.
- `src/lib/pipeline.js` — builds a full timeline/report for a given resolution + method.
- `src/components/` — `Dashboard` (animation comparison + timeline + optical-flow overlay),
  `MetricsView` (validation report/charts), `AboutView` (pipeline explanation + API contract).

## Swapping in a real backend

Replace `buildReport`/`fieldAt` calls with fetches to the endpoints sketched in the "Pipeline & About"
tab (`GET /api/frames`, `POST /api/interpolate`, `GET /api/metrics`), keeping the same
`{ t, isNative, truth, reconstructed, metrics }` row shape the UI already expects.
